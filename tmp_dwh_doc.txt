In fact, the DateVersion field is a datetime2 info about when a record is inserted or updated. This means that, a record R1 with a DateVersion value bigger than another record R2, has been inserted or updated after the last operation on record R2. This information could be useful when you need to import data incrementa lly every day from the DWH , avoiding doing full, slow imports everyday which could actually slow down the entire system . After the import phase, it is possible to get the maximum value of the DateVersion field of the records imported. This value can be stored in a configurati on table on DB and then used for the next import in order to save only the record inse rted or updated after the previ o u s one.
