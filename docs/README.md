## Docs Index

This folder contains project documentation consolidated from the repo root
and the `playabets-dashboard/` app directory.

Key files:

- `build.md`: older dashboard build tracker
- `pipeline-build-log.md`: Python pipeline and serving-layer build log
- `dashboard-build-tracker.md`: current dashboard build/deploy tracker
- `dashboard-calculations.md`: executive dashboard calculation notes
- `dashboard-research-notes.md`: early dashboard research notes
- `CHART_RATIONALE.md`: business rationale for dashboard charts
- `ideas.md`: selected dashboard design ideas
- `aws-rework-later.md`: backend/AWS migration notes

Note:

- `playabets-dashboard/ideas.md` and `playabets-dashboard/CHART_RATIONALE.md`
  were removed because they were exact duplicates of the copies in this folder.
